# Rompecabezas Bíblico - Antiguo Testamento

Juego interactivo y educacional en formato de rompecabezas estilo Tetris de 39 piezas sin rotación, correspondiente a los 39 libros del Antiguo Testamento (Protestante).

## Características
- **Tablero:** 12x13 casillas (156 bloques para 39 tetraminós).
- **Identidad de Fichas:** Cada ficha contiene el nombre y color oficial según la sección bíblica.
- **Efectos de Sonido:** Sintetizados automáticamente mediante Web Audio API.
- **Exportador PDF:** Botón listo para generar PDF imprimible y recortar en mesa física.
- **Automatización CI/CD:** Preparado con GitHub Actions.

## Ejecución local
Abre directamente `src/index.html` en tu navegador o ejecuta un servidor local en la carpeta raíz.
